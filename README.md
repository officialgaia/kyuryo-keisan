# 給料計算（kyuryo-keisan）

バイトのシフトを入れると、その月の給料と年収の見込みを計算するシンプルなWebアプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、データはブラウザの中（localStorage）だけに保存されます。

## できること

- **時給の設定と改定履歴** … 「◯月◯日から時給1,300円」のように行を足すと、その日以降のシフトに新しい時給が使われます
- **深夜割増** … 22:00〜5:00 は 25% 増し（時間帯・割増率は変更可）
- **残業割増** … 1日8時間を超えた分は 25% 増し。同じ日に2回シフトがあっても合算で判定
  - 深夜と残業が重なる時間は 50% 増し（25%＋25%）
- **休日手当** … 「土日は時給＋50円」など。土日を自動で休日扱いにでき、シフトごとに上書きも可能
- **交通費** … 出勤日ごと（1日1回）／月額定額／なし。シフトごとに金額を上書き可能。給与とは分けて集計
- **休憩** … 休憩時間（分）と開始時刻。開始時刻が空欄ならシフトの中ほどで計算（深夜割増の判定に影響するため）
  - 6時間超で45分未満、8時間超で60分未満の休憩なら警告（労働基準法34条）
- **日付をまたぐシフト**（21:00〜2:00 など）
- **締め日・支給日** … 末日締め／15日締めなど、当月・翌月払い
- **打刻の丸め** … 5・10・15・30分単位（出勤は切り上げ、退勤は切り捨て）
- **年間集計と年収の壁** … 支給日ベースで1〜12月分を合計し、壁までの残りと「このペースだと超えそう」を表示。壁の金額や「交通費込みで数えるか」は設定で編集可
- **テンプレート** … よく入るシフトをボタン1つで入力
- **CSV書き出し**（Excel で開ける BOM 付き）と **JSONバックアップ／復元**
- ダークモード対応・iPhone のホーム画面に追加して使える

## 使い方

- GitHub Pages で開く（このリポジトリの Pages を有効にしている場合）
- もしくは `index.html` をブラウザで直接開くだけでも動きます

iPhone では Safari で開いて「共有 → ホーム画面に追加」するとアプリのように使えます。

## 計算のルール

| 項目 | 内容 |
| --- | --- |
| 基本給 | 時給 × 実働時間 |
| 休日手当 | 休日手当（円/時）× 実働時間 |
| 深夜手当 | （時給＋休日手当）× 深夜割増率 × 深夜の時間 |
| 残業手当 | （時給＋休日手当）× 残業割増率 × 1日の上限を超えた時間 |
| 端数 | 締め月の合計で 1 円未満を四捨五入（各シフトの表示は目安） |
| 年間合計 | 支給日が その年の1〜12月 のものを合計 |

※ 年収の壁の初期値は目安です。税制・社会保険の制度は毎年のように変わるので、最新の情報を確認して設定で直してください。
※ 職場ごとのルール（週40時間超の残業、手当の種類など）とは違うことがあります。

## 開発

```sh
npm test   # 計算ロジック（calc.js）のテスト。Node.js 18 以上
```

- `calc.js` … 計算ロジック（画面に依存しない）
- `app.js` … 画面
- `index.html` / `style.css`
