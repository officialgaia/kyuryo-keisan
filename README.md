# 給料計算（kyuryo-keisan）

バイトのシフトを入れると、その月の給料と年収の見込みを計算するシンプルなWebアプリです。
ビルド不要の静的サイトで、データはブラウザの中（localStorage）だけに保存されます。

**https://officialgaia.github.io/kyuryo-keisan/**

## できること

- **時給を複数登録**（例：通常 1,200円／土日 1,300円／研修 1,100円）して、シフトごとに選ぶ
  - シフトには保存したときの時給が記録されるので、あとで時給を変えても過去の金額は変わりません
- **深夜割増** … 22:00〜5:00 は 25% 増し
- **残業割増** … 1日8時間を超えた分は 25% 増し（同じ日のシフトは合算）
- **深夜かつ8時間超** … 時給の 1.5 倍（割増率は設定で変更可）
- **交通費を複数登録**（例：電車 480円／バス 620円）して、シフトごとに選ぶ。1日1回（その日の最初のシフトの交通費）。毎月定額・なしも選べます。給与とは分けて集計
- **休憩**（6時間超で45分未満、8時間超で60分未満なら警告）、**日付をまたぐシフト**
- **締め日・支給日**（末日締め・15日締め、当月・翌月払いなど）
- **今年の合計と年収の壁**（支給日ベース。壁の名前と金額は設定で変更可）
- CSV書き出し、バックアップ（JSON）と復元
- ダークモード対応。iPhone では Safari の「共有 → ホーム画面に追加」でアプリのように使えます

## 計算のルール

| 項目 | 内容 |
| --- | --- |
| 基本給 | 時給 × 実働時間 |
| 深夜手当 | 時給 × 深夜割増率 × 深夜の時間（残業でない分） |
| 残業手当 | 時給 × 残業割増率 × 1日の上限を超えた時間（深夜でない分） |
| 深夜残業手当 | 時給 × 0.5 × 深夜かつ1日の上限を超えた時間（＝時給の1.5倍） |
| 休憩 | シフトの中ほどで取ったものとして計算 |
| 端数 | 締め月の合計で 1 円未満を四捨五入 |
| 年間合計 | 支給日がその年の1〜12月のものを合計 |

※ 年収の壁の初期値は目安です。制度は変わるので、最新の情報を確認して設定で直してください。

## 開発

```sh
npm test   # 計算ロジック（calc.js）のテスト。Node.js 18 以上
```

- `calc.js` … 計算ロジック（画面に依存しない。前のバージョンのデータの移行もここ）
- `app.js` … 画面
- `index.html` / `style.css`
